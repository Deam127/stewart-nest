Installing it

  1. Tap Download the app, then open the file when it's done (or find it in Files → Downloads).
  2. If the phone says it can't install apps from this source: tap Settings, switch on Allow from this source, then go back.
  3. Tap Install. If Play Protect warns that it doesn't know the app: More details → Install anyway.
  4. Open Nest, log in, allow notifications, then More → Switch on phone notifications.

Already have it? Installing a newer download over it keeps everything.
